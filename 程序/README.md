# 词笺（TangoNote）

词笺通过浏览器管理 MyNote 笔记，并提供 DictTango 查询页面；每条匹配笔记可通过“编辑”链接打开对应笔记编辑页，也可通过“删除”按钮在确认弹窗中删除笔记。笔记直接以 GoldenDict-MyNote 的文本文件格式保存，不使用 SQLite 作为主存储；MyNote 与本程序可共用同一笔记目录。

## 在 Android 设备上运行

服务应运行在 DictTango 所在的 Android 设备内。设备上的 `127.0.0.1` 指设备自身，因此无需依赖电脑端服务或 `adb reverse`。

1. 安装 Termux，并将项目放在 Termux 私有目录的 `~/dicttango/`，保持 `程序/`、`网页/` 的目录关系。
2. 在 Termux 安装 Python：`pkg install python`。
3. 要使用桌面一键入口，还需从与 Termux 相同的软件源安装 Termux:Widget。
4. 在 Termux 执行一次安装脚本：

   ```sh
   cd ~/dicttango/程序
   bash 安装Termux一键启动.sh
   ```
5. 将 Termux:Widget 小组件添加到桌面；如果桌面上已有空白小组件，点右上角刷新按钮。看到“启动笔记服务”后点击该项。服务就绪后，在设备浏览器或 DictTango 中打开 `http://127.0.0.1:8766/` 或查询端点。

也可在 Termux 中直接运行 `bash 启动笔记服务-Termux.sh`。启动入口会检查 Python、避免重复启动、等待网页就绪，并将日志写入 `~/.local/state/dicttango/service.log`。服务启动时会获取 Termux 唤醒锁，以降低锁屏后 CPU 休眠导致服务中断的概率；这会增加耗电。停止服务并释放唤醒锁：`bash 启动笔记服务-Termux.sh stop`。

若服务在锁屏或切到后台后仍被系统结束，请在 Android/手机厂商的电池设置中将 Termux 和 Termux:Widget 设为允许后台运行、允许自启动或“不受电池优化限制”，并避免清理 Termux 后台任务。唤醒锁不能阻止厂商强行结束应用；耗电或网络策略也可能影响后台访问。

Termux 终端若出现 `BrokenPipeError`，但随后请求仍返回 `200`，通常是浏览器提前关闭了某个连接，不代表笔记服务退出。当前版本会关闭该连接并继续服务。若创建笔记时返回 `409`，表示该词条在所选分组已存在；不要重复提交，回到笔记列表编辑已有词条。

若希望通过 Android 文件管理器查看笔记，可将笔记根目录设为 `/storage/emulated/0/Download/note`，并授予 Termux 文件访问权限。切换根目录本身不会搬动文件；迁移已有笔记时请先复制整个旧笔记目录（包括附件和子目录），确认新目录可用后再切换。

AnkiDroid J5 高光可通过只读接口 `/api/dictionary/j5` 获取 J5 分组中设为“会发送”的词头。浏览器管理首页的“高光管理”入口可搜索、分类、分页并批量调整发送状态；默认所有词头均发送，规则保存在默认的 `highlight-rules.json`，也可在首页“设置”中指定其他 JSON 路径。新目标路径不存在时会复制当前规则，已有文件则读取其规则；切换不会删除旧文件，也不改动笔记文件。接口只接受本机回环网页来源的跨域读取，不返回笔记正文；Termux 必须能够读取 J5 分组的 TXT 文件。AnkiDroid 的 `Android/data/.../collection.media` 对普通 Termux 进程不可读，因此若词典仅在该目录中，需先由有权限的文件传输方式复制到 Termux 可访问的目录；复制不会自动保持同步。

## 在 Windows 上运行

需要 Python 3.10 或更高版本，无第三方 Python 依赖。

- 双击 `启动笔记程序.bat`
- 或在本目录运行 `python app.py`

Windows 服务默认监听 `127.0.0.1:8766`，管理网页为 [http://127.0.0.1:8766/](http://127.0.0.1:8766/)。按 `Ctrl+C` 停止。Windows 上的这个地址只属于电脑自身，不能直接当作手机内的 `127.0.0.1`。

### Windows 稳定版发布与手动更新

版本号统一维护在 `version.py`。发布前在项目根目录执行：

```powershell
python -B 程序\build_release.py --output-directory 发布
```

会生成版本化 ZIP 和同名 JSON 清单；清单记录版本、Python 最低版本、文件数和 ZIP 的 SHA-256。发布时应将 ZIP 与清单一起上传到可信的 HTTPS 发布页（例如 GitHub Releases），并附上本版更新说明。程序目录和网页目录会打包；`程序\settings.json`、`程序\note\`、`程序\highlight-rules.json`、测试代码和缓存不会进入 ZIP，避免把个人设置、笔记和高光数据发到发布包中。

用户手动更新时，先停止服务并备份当前程序文件夹，再将已下载的 ZIP 解压到现有项目根目录，保留本机设置和笔记数据；使用清单中的 `sha256` 与 `Get-FileHash <压缩包路径> -Algorithm SHA256` 结果核对。当前项目没有配置公开仓库或发布地址，因此尚未启用网页内的在线检查/下载，也不会自动覆盖运行中的程序；确认发布渠道及将来的一键安装方式前，不应将更新包放入笔记同步目录。

### Windows 多设备 OneDrive 同步

在首页齿轮“设置”中选择 OneDrive 客户端已经同步到本机的文件夹；在另一台 Windows 电脑上选择同一个 OneDrive 云端文件夹对应的本地路径。配置后点击“立即同步”，功能会同步 MyNote TXT、分组资源文件和当前高光规则。它是手动同步，不使用 Microsoft Graph、不保存账号凭据，也不会自动在后台运行。同步文件不会由程序额外加密，请只使用自己信任的 OneDrive 帐户；请等 OneDrive 显示同步完成后再操作另一台设备。

同步过程中只自动应用单边变化；同一文件的本地与云端内容同时变化时会保留双方版本并提供冲突选择。每台设备的笔记根目录及自定义 TXT/资源路径仍是本机设置。云端历史数据保存在所选文件夹下的 `.dict-tango-sync`，请不要手动编辑或删除该子目录。版本历史暂不自动清理；关闭同步不会删除任何数据。Android/Termux 目前尚未接入此同步方式。

需要了解同步协议、文件结构、合并规则或后续开发约束时，请参阅[数据同步功能开发说明](../数据同步功能开发说明.md)。

Windows 启动脚本当前默认开启测试模式（`TEST_MODE=1`）。将 `启动笔记程序.bat` 中该值改为 `0` 可关闭；直接运行 `python app.py` 默认关闭，也可添加 `--test-mode` 开启。测试信息入口显示在页面左下角，默认折叠，点击后展开；关闭测试模式后恢复普通页面。

服务只接受本机 Host；浏览器写请求还会检查 Origin。不要为了手机直连而随意把服务改为监听所有网卡。

## MyNote 文件与目录

默认笔记目录是 `程序\note\`（可用 `--notes <目录>` 指定）。也可在笔记管理首页点击顶栏齿轮进入“设置”，从“本地笔记根文件夹”选项切换；设置会保存到 `程序\settings.json`，之后启动时自动使用。命令行显式指定 `--notes` 时优先使用该参数。切换根文件夹不会搬动或删除原目录中的内容。每个自定义分组右侧的“⋯”菜单中点击“编辑”，可分别将该组 TXT 笔记文件和资源文件夹设为默认或自定义路径；自定义 TXT 须为已有且文件名符合分组命名规则的 MyNote 文件。资源文件夹默认位于 TXT 同目录下的 `MyNote-[Default]\` 或 `MyNote-<分组名>\`，也可单独指定已有资源目录。路径切换不会移动或删除文件，组改名时路径会随组更新。目录结构遵循 MyNote：

```text
note/
  MyNote-[Default].txt
  MyNote-<分组名>.txt
  MyNote-[Default]/                # 默认分组附件
  MyNote-<分组名>/                 # 该组图片、音频、视频等附件
  config/                          # 本程序的一次性旧版迁移标记
```

每条笔记使用 MyNote 条目格式：

```text
词条
<font size=5>词条</font>
笔记正文 HTML 或文本
</>
```

默认组在界面显示为 `[Default]`，使用 `MyNote-[Default].txt` 和 `MyNote-[Default]\` 附件目录。自定义分组使用 `MyNote-<分组名>.txt`，附件默认保存在同目录下的 `MyNote-<分组名>\`；也可分别为每组指定 TXT 文件和资源目录的自定义路径。不会识别或自动迁移旧格式 `GoldenDict-MyNote.txt` 和 `GoldenDict-MyNote-<分组名>.txt`，现有文件需要手动改名。保存笔记时只替换目标条目，其他文件内容保留。MyNote 若与本程序同时写同一个目录，请避免同时编辑同一词条。

旧版 `数据\notes.sqlite3` 仅作一次性迁移来源：首次启动且目标目录尚无 MyNote 笔记文件时，自动导入其中的分组与笔记；源 SQLite 不会被删除。已经有 MyNote 笔记文件时，以这些文件为准，不会自动合并旧数据库。迁移状态记在 `note\config\legacy-sqlite-migrated`。

## 浏览器管理功能

- 浏览器中新建和编辑笔记使用弹窗，不离开管理页；编辑器分组框提供已有分组的下拉建议并记住上次选择，也允许手动输入新分组名称，保存时自动创建。支持删除笔记、词条/正文搜索、分组筛选，以及在 Library 栏创建/重命名/删除空分组。新建分组时先填写名称，再选择 TXT 笔记文件和资源文件夹路径；确认后才创建分组文件，若选择自定义 TXT 路径就直接在该位置创建，不会先在笔记根目录生成空文件。取消路径设置会返回名称输入，不会创建分组。已有分组仍可从菜单修改路径。笔记根文件夹可通过顶栏齿轮打开“设置”后切换。桌面首页左列从上到下为 Library 与当前分组信息，笔记显示区在右侧与左列等高；窄屏切换为单列。Library 词条列表桌面端最大为视口高度的 42% 且不超过 360px，窄屏最大 210px，超出后可纵向滚动；过长词条会以省略号截断，不产生横向滚动。顶部“高光管理”进入 J5 词头管理页，可分页搜索、筛选发送状态、分类并批量设置；其余顶部操作可导出 JSON、打开导入备份弹窗或切换笔记根文件夹。
- 编辑器支持可视化富文本和 HTML 源码两种模式，可在面板中直接编写 HTML；也包括常用格式、标题、引用、列表、表格、链接、粘贴、正文查找/替换。
- 浏览器可上传图片、音频和视频，保存到 MyNote 分组资源目录。HTML 源码模式粘贴时，工具栏“本地化图片”开关（默认开启）控制是否将剪贴内容里的远程图片或 base64 位图保存到当前分组；下载受公网地址、文件类型、数量和 20 MB 大小限制，失败会保留原内容并提示。包含 HTML 与图片文件的剪贴板在源码模式优先处理 HTML；单独粘贴图片则作为附件上传。查询其他笔记可写 `[http://127.0.0.1:8766/lookup?word=词条]`，也可追加 `&group=分组名` 限定分组；显示为可点击链接。旧语法 `@@@LINK=词条` 仍会展开引用，循环或缺失引用会显示提示。
- 源码模式“删除代码”会清空源码输入框；保存后，仅删除不再被任何笔记引用的本地图片，共享图片保留，取消编辑不会删除附件。
- DictTango 查询页会自动加载命中笔记所属分组目录中的 `.css` 和 `.ttf`/`.otf`/`.woff`/`.woff2` 文件，并为字体文件名生成同名字体族。将 MathJax 本地发行版放到对应分组目录即可使用 LaTeX；启动时需通过 `python app.py --allow-note-scripts` 启用分组目录中的 `.js` 文件（Windows 启动脚本也可附加此参数）。脚本仅允许从本机笔记目录加载，并只对查询页生效。
- JSON 备份可导出与合并导入。导入前会校验数据，已有同组同词条会被备份内容更新。
- 文件存储层不主动清洗 MyNote 正文。浏览器/查询页显示时会过滤脚本、事件属性、不安全链接与不支持的资源类型；未修改直接保存会保留原始正文，编辑后保存的正文则是过滤后的安全 HTML。

逐项功能状态、与参考 MyNote 脚本的差异及人工检查清单见[网页笔记与 MyNote 功能对比](../网页笔记与MyNote功能对比.md)。
各网页页面、查询路由和操作流程见[网页页面与路由说明](../网页页面与路由说明.md)。

## DictTango 查询

查询端点：

```text
http://127.0.0.1:8766/lookup?word=查询词
http://127.0.0.1:8766/lookup?word=查询词&group=分组名
```

`word` 为查询词，`group` 为可选的分组名；不提供 `group` 时查询全部分组，提供后只查询该组。查询词和分组名中的特殊字符应使用 URL 编码。旧路径 `/search/查询词` 和 `/serach/查询词` 不再支持。查询词大小写不敏感；不指定分组时，同词不同分组会分别显示。每条查询笔记提供“删除”按钮（确认弹窗）和“编辑”链接；编辑后会跳转至对应笔记编辑页。新建笔记仍在浏览器管理页完成。

DictTango 自定义在线词典需要把其查词占位符放到 `word` 参数。占位符准确写法及 DictTango WebView 的本地 HTTP 行为需在目标版本实测。

## 与 MyNote 的差异

| 功能                                           | 状态与原因                                                                                                                                                                  |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文件格式、分组文件与附件目录                   | 已兼容 MyNote 的纯文本格式和命名约定                                                                                                                                        |
| 富文本、HTML 源码、粘贴、查找替换、图片/音视频 | 已实现浏览器版本；显示时会过滤脚本、事件属性和不安全链接                                                                                                                    |
| `@@@LINK` 引用、分组、查询                   | 已实现；循环引用有深度保护                                                                                                                                                  |
| 未过滤的 raw HTML、脚本和事件处理器            | 不执行。浏览器管理页与 DictTango 查询运行在 WebView 中，执行笔记脚本会带来跨站脚本和本机数据风险                                                                            |
| 分组目录 CSS 与字体文件                        | 查询页会从命中笔记所属组目录自动加载 CSS 与常见字体文件；CSS 的字体、图片等资源受同源/CSP 限制                                                                              |
| 分组目录 JavaScript                            | 默认关闭；对可信笔记使用 `--allow-note-scripts` 启用。脚本只能从本机组目录加载，执行脚本可能读取/改变页面内容，因此不要对不可信笔记开启                                   |
| 粘贴时自动本地化远程图片                       | 部分实现。仅在 HTML 源码粘贴/清理且工具栏开关开启时下载通过公网地址校验的有限格式位图；不自动抓取笔记中任意远程图片或音视频 URL。浏览器上传本地附件仍可用于图片、音频和视频 |
| MathJax/LaTeX                                  | 通过本地 MathJax JavaScript 包渲染；需将 MathJax 文件放入笔记组资源目录并使用 `--allow-note-scripts` 启动。不开脚本时保留并显示原始公式文本                               |
| 大笔记分片导航与延迟加载                       | 未实现。浏览器使用单一富文本编辑区，正文上限为 5 MB；超大笔记建议拆分条目                                                                                                   |
| Windows 置顶、窗口位置/尺寸、Tk 剪贴板清洗器   | 未实现。这些是 MyNote Tkinter/Windows 原生窗口专属能力，网页无法可靠控制                                                                                                    |
| 查询次数统计                                   | 未实现。MyNote 默认配置关闭此功能；网页查询不记录查询次数                                                                                                                   |
